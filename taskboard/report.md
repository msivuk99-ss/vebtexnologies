## Лабораторна робота 4. Git у терміналі

1. **Що змінилося у виводі `git status` після `git add`?**
   Файл перемістився із секції невідстежуваних або змінених (червоних) у секцію `Changes to be committed` (зелених) — тобто потрапив в індекс (staging area) для наступного коміту.

2. **Що показує `git diff`?**
   Показує построкову різницю між поточними незбереженими в індекс змінами у робочій директорії та останнім комітом (додані рядки позначаються `+`, видалені — `-`).

3. **Чим відрізняється `git switch main` від `git merge`?**
   `git switch main` просто перемикає робочу директорію на гілку `main`, а `git merge` об'єднує історію змін з іншої гілки в поточну.

4. **Чому виник конфлікт і як ти його розв'язав?**
   Конфлікт виник через те, що в двох різних гілках (`main` та `ukr-title`) було змінено один і той самий рядок заголовка `<h1>` у файлі `index.html`. Я відкрив файл у VS Code, видалив маркери конфлікту, об'єднав текст заголовка, зберіг файл і зафіксував результат новим комітом.
